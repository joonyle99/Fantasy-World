Setup Guide

FMOD를 Unity 프로젝트에 연동하기

FMOD Studio 프로젝트 생성부터 Unity에서 사운드를 재생하기까지

1

FMOD Studio 설치 및 프로젝트 생성

fmod.com/download에서 FMOD Studio를 설치한다 (무료 계정 가입 필요). 설치 후 새 FMOD Studio 프로젝트를 만들고, 효과음 · 배경음 에셋을 이벤트(Event)로 구성한다.

  • Bank는 최소 Master Bank 하나로 시작해도 충분하다.
  • 거위 울음, 발소리처럼 반복되는 사운드는 Multi-Instrument로 묶고 파라미터로 랜덤 배리에이션을 준다.
2

Unity Integration 패키지 설치

FMOD for Unity 패키지(.unitypackage)를 받아 프로젝트에 임포트하거나, Unity Package Manager에서 git URL로 추가한다.

  • 임포트 후 상단 메뉴에 FMOD 항목이 생기면 정상 설치된 것.
  • FMOD Studio 버전과 Unity Integration 버전이 서로 맞는지 확인 (버전 불일치 시 Bank 로드 에러 발생 가능).
3

Settings 창에서 프로젝트 연결

FMOD → Edit Settings에서 다음을 설정한다.

  • Source: 1번에서 만든 FMOD Studio 프로젝트의 .fspro 파일 경로 지정
  • Build Directory 등은 기본값으로 두고 시작해도 무방

이후 FMOD Studio에서 File → Build로 Bank를 빌드하면 Unity가 자동으로 최신 Bank를 인식한다.

4

씬에 FMOD 초기화 오브젝트 배치 (선택)

대부분의 초기화는 Integration 패키지가 자동으로 처리하지만, 리버브 존이나 3D 리스너를 쓸 경우 FMOD Studio Listener 컴포넌트를 메인 카메라나 플레이어 오브젝트에 붙인다.

5

코드에서 사운드 재생

가장 단순한 형태의 원샷 이벤트 재생:

using FMODUnity;

public class GooseHonk : MonoBehaviour
{
    [SerializeField] private EventReference honkEvent;

    public void PlayHonk()
    {
        RuntimeManager.PlayOneShot(honkEvent, transform.position);
    }
}

지속되는 사운드(발소리 루프 등)는 EventInstance를 직접 생성해 시작/정지를 제어한다:

private FMOD.Studio.EventInstance footstepInstance;

void Start()
{
    footstepInstance = RuntimeManager.CreateInstance(footstepEvent);
}

void OnDestroy()
{
    footstepInstance.release();
}
주의 FMOD Studio에서 Bank를 다시 빌드한 뒤에는 Unity 에디터에서 FMOD → Rebuild Bank Data (또는 재생 시 자동 갱신)를 확인해야 최신 사운드 변경사항이 반영된다. 빌드를 깜빡하면 이전 버전 사운드가 재생되는 문제가 흔하게 발생한다.
FMOD를 선택한 배경은 audio-middleware-fmod-vs-wwise.html 참고.
